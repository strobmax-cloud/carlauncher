# Новый год v4 — макеты (на утверждение, APK не выпускался)

Отрисовано настоящим приложением (Robolectric, 1280×720): C и D × Главная / Музыка / «Фон».
Контакт-лист: ny4-contact-sheet.png.

## Принципы (что изменилось против v1.7.8)
- **Гирлянда — одна непрерывная нить** по всему верхнему краю (на «Фоне» продолжается вниз по правому краю). Она ничего не обходит и не рвётся: украшения нарисованы **за** интерфейсом, а карточки лежат поверх. Над свободным текстом (часы, погода) нить поднимается к краю, лампочки там приглушены. Шаг лампочек везде одинаковый.
- **Ветки — композиция, а не наклейки**: пушистая группа в левом верхнем углу (из неё выходит гирлянда) и маленький ответный букет внизу справа, в свободном промежутке между вкладками и кнопками громкости. Он «утоплен» в сугроб и никогда не заходит на контент. Ветки очищены от каймы и ореола, приглушены (насыщенность −45 %, холодный оттенок, иней сверху) под тёмный UI. На C слева и справа нет украшений — там эквалайзер.
- **Снег сдержанный**: низкий ровный сугроб, тонкие шапки только на широких карточках (на круглых кнопках их нет). Убраны лишние шишки, гирлянды по бокам и обрывки.

## Вариант 1 — Classic warm
Фото-ветки (очищенные, приглушённые) + тёплая гирлянда C7 на витом проводе с мягким свечением + шары только в нижнем букете + сугроб и тонкие снежные шапки.

## Вариант 2 — Minimal elegant
Без веток. Две нити микро-огоньков на медной проволоке (передняя и задняя — глубина), иней в углах (TL/BR), внизу морозная дымка вместо сугроба, на широких карточках тонкая линия инея. На «Фоне» — световые «занавеси» у самых краёв экрана.

## Найденный баг v1.7.8
`Festive.scan` неверно считал границы текста, выровненного по центру (getLineLeft → ≈ −523 478), поэтому часы в D «Главная» не считались препятствием. Исправлено в ветке design-newyear-v4, войдёт в следующий релиз.
